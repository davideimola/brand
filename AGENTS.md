# AGENTS.md

This repo is the single source of truth for the brand. Read `docs/brand.md` before touching anything.

- Source files: `tokens/tokens.json`, `src/geometry.mjs`, `src/draw.*`, `src/design.md`, `scripts/build.mjs`, `docs/`.
- Tests: `pnpm test` (Node's built-in runner, no dependencies).
- Generated files: `dist/`, `assets/`, `DESIGN.md`. Never edit them by hand; run `pnpm build`.
- Package manager: pnpm. Node only, no other build tools.
- Copy in English, no em dashes.
